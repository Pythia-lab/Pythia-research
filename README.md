# PYTHIA · Company Research

Personal equity research library: business analysis, One Page sheets, DCF valuations and fair-value gap analysis
versus Morningstar and S&P — in English and Chinese.

Static site (no build step): open `index.html`, or visit the GitHub Pages URL.
Content lives in `data/companies.js`; report files in `reports/<company-id>/`.
See `使用说明.md` for how to add a company.

All content is personal research for learning purposes only and is not investment advice.
